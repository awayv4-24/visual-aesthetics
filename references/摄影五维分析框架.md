# 摄影五维分析框架（V0.1 参考细则）

> 配套 `visual-aesthetics` Skill 使用。逐维给出：看什么、常见判断、改进建议的因果链示例。  
> 标注约定：【技术】可验证事实｜【视觉】中性描述｜【表达】解读｜【审美】专业共识判断｜【个性化】个人口味。

---

## D1 构图与画面组织

**看什么**

- 主体是否明确、是否足够"重"于画面；
- 主体位置：三分线 / 中心 / 边缘 / 对角线；
- 引导线（路、墙、光影）把视线带向哪里；
- 负空间（留白）是否服务主题；
- 画面边界是否切掉关键元素（如头顶、手肘）；
- 平衡 vs 张力：对称稳重，打破平衡产生动势。

**常见判断**

- 【视觉】"主体偏左下三分线，右侧大片天空为负空间。"
- 【审美】"在表现空旷/孤独时，偏置构图成立；若主题是主体细节，则负空间偏多。"
- 【技术】"人物头顶被上边缘裁切，观感局促。"（仅当确实裁切时）

**因果链示例**

- 当前情况「主体居中」→ 先判断表达目标：若求稳定/对称，居中可成立；若需引导视线，再考虑偏移。→ 预期：是否改动取决于意图，不默认居中即错。
- 当前情况「背景杂乱削弱主体辨识」→ 可分别尝试：调整机位/改变距离分离主体与背景，或等待背景干扰移出，或依表达需要控制景深虚化（虚化会损失环境，是取舍）。→ 预期：主体更突出，但环境信息可能减少。
- 当前情况「地平线切在正中，上下各半」→ 调整方式「依主题上移/下移地平线（天空为主则上 1/3，地面为主则下 1/3）」→ 预期视觉变化「画面重心明确，不再呆板」。

## D2 光线与影调

**看什么**

- 光向：顺光 / 侧光 / 逆光 / 顶光 / 底光；
- 光质：硬光（清晰阴影、强反差）vs 软光（柔化、低反差）；
- 影调：高调（亮、轻）、中间调、低调（暗、重）；
- 明暗对比是否让主体突出；
- 是否有悦目的体积感与质感（如侧光下的纹理）。

**常见判断**

- 【视觉】"侧逆光，主体边缘有轮廓光，脸部转暗。"
- 【审美】"低调处理强化了沉静氛围，与本片主题一致。"
- 【技术】当前图像中云层高光区域呈现明显的无细节白色；是否由拍摄时曝光溢出造成，仍需结合原始文件及拍摄信息确认（不得仅凭 JPEG 直接断言拍摄时曝光过度）。

**因果链示例**

- 当前情况「正午顶光，人物眼窝阴影重、显疲惫」→ 调整方式「改到阴影处或晨昏侧光拍摄」→ 预期视觉变化「面部过渡柔和，质感更自然」。
- 当前情况「画面整体偏灰、缺乏反差」→ 调整方式「后期适度压暗暗部、提亮高光，拉开影调」→ 预期视觉变化「体积感增强，主体更立体」。

## D3 色彩关系

**看什么**

- 整体色相倾向（暖/冷/中性）；
- 主色与辅色关系：互补（对比强）、类比（和谐）、单色（统一）；
- 饱和度策略：高饱和张扬，低饱和克制；
- 色彩是否服务于情绪与主题；
- 有无刺眼、互相打架的杂色。

**常见判断**

- 【视觉】"以蓝青冷调为主，一点暖色灯光作点缀。"
- 【审美】"冷暖小面积对比让视野落点清晰，是有效处理。"
- 【个性化】"我个人更偏爱去掉那点暖色、做成纯冷调。"（标【个性化】，不影响专业判断）

**因果链示例**

- 当前情况「环境色杂乱、红绿蓝同框抢眼」→ 调整方式「统一为同色系或降低次要色饱和度」→ 预期视觉变化「画面更整体，主题更突出」。
- 当前情况「色彩平淡、情绪弱」→ 调整方式「强化冷暖对比（如压暗冷背景、提亮暖主体）」→ 预期视觉变化「情绪张力上升」。

## D4 空间、景深与视觉层次

**看什么**

- 前景 / 中景 / 背景是否分层清晰；
- 景深：全景深（前后皆清）vs 浅景深（主体清、背景虚）；
- 透视与空间纵深：透视关系主要由**拍摄位置与拍摄距离**决定（距离越近，近大远小、纵深感越强）；**焦段改变的是视角与取景范围**，并不直接制造透视。常见的"广角夸张纵深、长焦压缩空间"观感，通常是因为摄影者换用不同焦段时为保持主体大小而改变了拍摄距离——本质是距离变化，而非焦段本身。
- 是否有"空气感"/空间纵深，还是平面化。

**常见判断**

- 【视觉】"浅景深，背景化为色块，主体跳出。"
- 【审美】"在突出单人肖像时浅景深成立；在交代环境叙事时则宜收小光圈保留层次。"
- 【技术】"焦点落在背景而非主体，主体发虚。"（仅当确实失焦）

**因果链示例**

- 当前情况「前景空、主体与背景贴在一起显平」→ 调整方式「纳入前景元素（草、枝）并收小光圈保层次」→ 预期视觉变化「空间纵深拉开，画面更立体」。
- 当前情况「背景抢戏分散注意、与主体贴在一起显平」→ 调整方式「靠近主体以增大其与背景的透视差，或开大光圈虚化背景」→ 预期视觉变化「主体隔离感强，观看更聚焦」。

## D5 视觉语言与表达意图（含时机与瞬间判断）

**看什么**

- 画面在"说什么"：情绪、叙事、观点；
- 决定性瞬间：人物姿态/动作/表情/事件节点是否到位；
- 形式是否为内容服务，还是仅为好看；
- 是否存在更优时机（再等一秒会怎样）；
- 留白、模糊、残缺是否是有意为之的表达。

**常见判断**

- 【表达】"人物回眸与背景空旷形成'被世界抛下'的孤寂感，这是一种合理解读。"
- 【审美】"瞬间抓得住：动作顶点定格，张力成立。"
- 【待核实】"作者是否刻意让主体背对镜头以制造疏离感——意图无法确认，列出此可能。"

**因果链示例**

- 当前情况「人物行走姿态平淡、脚刚离地显僵」→ 调整方式「等待步伐最舒展或重心交替的瞬间再拍」→ 预期视觉变化「动态自然、瞬间更有张力」。
- 当前情况「想表达'等待'但画面信息过满」→ 调整方式「简化元素、加大空旷留白」→ 预期视觉变化「孤独/等待的情绪被放大」。

---

## 使用纪律提醒

- 重要判断先明确类型（【技术/视觉/表达/审美/个性化】）再下笔；纯观察性描述不必强贴标签；
- D5 的"意图"凡不能从图像确证，一律 `待核实`/`无法确认`，不多重脑补；
- 同一维度可并列多种改进可能，不必只给一条"标准答案"。
