# 视觉美学 · 摄影教学 Skill（Visual Aesthetics）

一个**教学取向**的摄影分析 Agent Skill：不做「照片评分器」，而是做**会认识学生、会分层教学、懂得克制**的摄影教师。

为 Agent 环境（WorkBuddy / Claude Code 等支持 `SKILL.md` 约定的运行时）设计，核心方法论与平台无关。

---

## 它和市面上的 AI 摄影点评有什么不同

| 常见 AI 摄影工具 | 本 Skill |
|---|---|
| 0–100 打分、星级、滑杆值 | **不评分**，给核心判断与因果链建议 |
| 一次性报告流 | **六环节教学闭环**：诊断→定调→讲解→示范→练习→回响 |
| 不认识用户 | **主动了解**水平/题材/目标/用途语境，因材施教 |
| 反馈不可溯源 | **学术＋作品配对**：理论出处 + 代表性实践，引用纪律严格 |
| 静态大图/生成式样图 | **精致交互 HTML**：可点击标注点、前后对比滑块、折叠模块、思维导图 |
| 单一审美当普世标准 | **评价类型区分**（技术/视觉/表达/审美/个性化）＋语境化判断 |
| 话术式鼓励 | **C 型人格**（亦师亦友的创作型导师）＋诚实护栏＋情绪边界 |

## 安装

把本仓库放进 Agent 的用户级技能目录即可（以 WorkBuddy 为例）：

```bash
git clone https://github.com/<your-name>/visual-aesthetics.git
mkdir -p ~/.workbuddy/skills
cp -r visual-aesthetics ~/.workbuddy/skills/visual-aesthetics
```

目录结构：

```
visual-aesthetics/
├── SKILL.md                        # 主文件（方法论与纪律）
└── references/
    ├── 摄影五维分析框架.md          # D1–D5 逐维检查清单
    ├── 摄影核心理论参考手册.md      # 已核实理论出处
    ├── 视觉反馈交互页模板.html      # 苹果风交互评审页模板
    └── 知识思维导图模板.html        # 知识可视化模板
```

> 模板为单文件、零依赖，可直接在浏览器打开预览与二次修改。

## 使用

在任意会话中发送照片并提出摄影相关问题即可触发，例如：

- 「这张怎么样？」（快速点评：核心判断 + 2–3 条因果链建议）
- 「帮我做一次五维详析」（以核心判断领起，只展开支撑判断的维度）
- 「为什么逆光人像总是灰？」（专项答疑：一个核心点 + 一个话口）
- 「把这 9 张活动照按发稿标准过一遍」（交互评审页 + 分档 + 交付建议）

## 设计要点

- **照片先行**：首条消息带照片时，先看片、先真实反应，不寒暄调查。
- **克制**：日常轮默认「一个核心点（2–5 句）+ 一个话口」，长文只在用户要详析或交付评审页时出现。
- **保真视觉反馈**：裁切/影调/标注/对比全部走确定性像素操作与 overlay，**不重绘、不替换原始主体**；D 档「优化演示」默认降级，禁止生成式重绘冒充真实修改结果。
- **归属核验**：批量处理陌生照片先核验来源（文件名规律、尺寸体系、EXIF、疑似名家作品），存疑先问。
- **第一性原理护栏**：每个交互/版式功能都要回答「为用户解决了什么切实问题」，不为炫技加功能。

## 已知限制

- 视觉能力上限取决于运行平台（图像读取、Pillow 等本地能力）；无相应能力时会如实说明并降级为文字方案。
- 知识边界明确：引用仅取可核实出处，无法确认一律标注【待核实】，不编造作者、年份、原话。
- 不持久化用户画像：用户认知仅作会话内工作假设（隐私优先的主动取舍）。
- 当前为 V0.1.8，仍在迭代；欢迎通过 Issues 提交真实使用反馈。
